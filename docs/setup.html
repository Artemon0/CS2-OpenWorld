Build & deploy

Use the repository installer to check dependencies, configure and build, or follow the manual steps below.

Requirements

  • CS2 dedicated server with Metamod:Source.
  • CMake 3.19+ and 64-bit MSVC on Windows or Clang on Linux.
  • Initialized hl2sdk-cs2 and metamod-source submodules.
  • PostgreSQL 14+ and runtime libpq for persistent operation.

Quick setup

Installer checks dependencies, initializes submodules and builds. Check mode reports requirements without changing anything.

# Linux: scripts/install.sh --check, then scripts/install.sh
# Windows: .\scripts\install.ps1 -Check, then .\scripts\install.ps1

Manual build

git submodule update --init --recursive
cmake -S . -B build -A x64
cmake --build build --config Release

On Linux use Clang and Ninja: cmake -S . -B build-linux -G Ninja -DCMAKE_BUILD_TYPE=Release, then cmake --build build-linux -j.

Database & configuration

Copy .env.example to .env, set unique secrets, create restricted application and migration roles, apply migrations 001–004 in order, then grant application permissions. Configure the server in configs/openworld.ini. Never commit secrets.

Build output contains a package directory. Copy its addons/ and cfg/ contents into server game/csgo/ and provide libpq at runtime. Full SQL and troubleshooting: English guide / Russian guide.

Cluster routing

Apply migration 004 and keep routing config and PostgreSQL consistent on every server. Redirects reconnect; they are not seamless transfers.
