Roadmap

This file replaces the placeholder headers that used to live under src/modules/ and src/services/. Each of those files contained nothing but class X;, was included by nothing, and made the module layout look more complete than it is. The intent is recorded here instead.

Text output

For a reply to one player, use OpenWorldPlugin::SendPlayerText(slot, channel, text) in src/core/plugin.cpp. It sends through the UI manager (respecting the configured adapter) and falls back to the engine console if that path is unavailable. For a broadcast chat announcement, utils::CPrintChatAll(format, ...) sends to all players. utils::ClientPrintFilter is the lower-level helper for custom recipient filters. The dedicated chat-helper API was removed because it had no callers.

Known gaps in the current implementation

  • src/core/plugin.cpp is a single large translation unit; the chat command router, route coordinator, character/settings coordinators, and hook binder are natural extraction points.
  • The Offsets block in gamedata does not define Touch, StartTouch, EndTouch and CollisionRulesChanged; the corresponding CBaseEntity helpers are unused today and degrade to a no-op. tools/update_offsets.py --check --strict reports them.
  • Character, inventory, and wallet data are never cached; every read goes to PostgreSQL. That is correct but may need an explicit read-through cache once player counts grow.
  • Event delivery is single-threaded (game thread). EventBus::Publish is synchronous and rejects re-entrant cycles past MaxPublishDepth; Enqueue/DispatchPendingEvents (drained once per OnGameFrame) deliver owned copies for self-publishing listeners. A listener that unbinds itself from inside its own callback skips the remaining listeners of the same publish on purpose; a listener must not unbind another one mid-publish. Cross-thread publishing is unsupported.
  • TransferManager is purely in-process with no locks; call it from the game thread only. It is the validation state machine, not the cross-server coordinator: reservation, tokens, ownership fencing, and the destination arrival handshake are still open (ADR-025).
