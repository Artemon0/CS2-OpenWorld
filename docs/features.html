What works today

Implemented, experimental and planned work are marked separately to set clear expectations.

IMPLEMENTED

Player & character

Engine-confirmed Steam auth; async settings and character loading; list, create and select characters.

IMPLEMENTED

Cluster routing

Persistent server assignment, !go redirect and configured XY zone routing. Redirect means reconnect.

IMPLEMENTED

Data & commands

PostgreSQL character, settings, inventory snapshot and wallet services.

IMPLEMENTED

Text interface

!hud text HUD, notifications and map name command.

EXPERIMENTAL

Particle menu

Opt-in runtime; Workshop resources and live-game validation required. Off by default.

PLANNED

World gameplay

Seamless transfers, position restoration, NPCs, quests, vehicles, full inventory gameplay and graphical map panels.

Current player commands

  • !character list|create |select
  • !inventory prints the stored snapshot to client console.
  • !balance displays the selected character wallet.
  • !hud [on|off|toggle] toggles text HUD.
  • !go saves route and reconnects player.

See setup, architecture and the repository README.
